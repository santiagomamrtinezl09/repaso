# Guía de Markdown 🚀

Este documento contiene ejemplos de los principales elementos de Markdown utilizados en GitHub para crear documentos organizados y fáciles de leer.

## 1. Headers (Encabezados)

Los encabezados permiten organizar la información mediante diferentes niveles de títulos.

```markdown
# Encabezado 1
## Encabezado 2
### Encabezado 3
#### Encabezado 4
```

# Encabezado 1
## Encabezado 2
### Encabezado 3

## 2. Lists (Listas)

Las listas permiten organizar elementos sin necesidad de enumerarlos.

```markdown
- Python
- Java
- JavaScript
- C++
```

- Python
- Java
- JavaScript
- C++

## 3. Énfasis (Emphasis)

Permite destacar palabras o frases utilizando negrita, cursiva o texto tachado.

```markdown
**Texto en negrita**

*Texto en cursiva*

~~Texto tachado~~
```

**Texto en negrita**

*Texto en cursiva*

~~Texto tachado~~

## 4. Ordered Lists (Listas ordenadas)

Permiten organizar información mediante números.

```markdown
1. Aprender Python.
2. Aprender Git.
3. Aprender GitHub.
4. Crear proyectos.
```

1. Aprender Python.
2. Aprender Git.
3. Aprender GitHub.
4. Crear proyectos.

## 5. Images (Imágenes)

Permiten insertar imágenes utilizando una dirección web o una ruta de archivo.

```markdown
![Descripción de la imagen](URL_DE_LA_IMAGEN)
```

Ejemplo:

```markdown
![Logo de GitHub](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)
```

## 6. Links (Enlaces)

Permiten insertar enlaces a páginas web.

```markdown
[Visitar Google](https://www.google.com)
```

[Visitar Google](https://www.google.com)

## 7. Block Quotes (Citas)

Permiten destacar una frase o una cita.

```markdown
> La práctica hace al maestro.
```

> La práctica hace al maestro.

## 8. Backslash Escapes (Caracteres especiales)

La barra invertida permite mostrar caracteres que normalmente tienen una función especial en Markdown.

```markdown
\*Este texto no aparece en cursiva\*
\# Esto no es un encabezado
```

\*Este texto no aparece en cursiva\*

## 9. Username Mention (Menciones de usuarios)

En GitHub se puede mencionar a otros usuarios utilizando el símbolo @ seguido de su nombre de usuario.

```markdown
@nombredeusuario
```

Ejemplo: @octocat

## 10. Task List (Lista de tareas)

Permite crear listas de actividades pendientes o completadas.

```markdown
- [x] Crear una cuenta de GitHub.
- [x] Crear un repositorio.
- [ ] Aprender Markdown.
- [ ] Crear mi primer proyecto.
```

- [x] Crear una cuenta de GitHub.
- [x] Crear un repositorio.
- [ ] Aprender Markdown.
- [ ] Crear mi primer proyecto.

## 11. Issue References (Referencias a problemas)

Permiten hacer referencia a incidencias o problemas registrados dentro de un repositorio de GitHub.

```markdown
#1
```

Si existe una incidencia con el número 1 en el repositorio, GitHub puede convertir esta referencia en un enlace.

## 12. Fenced Code Blocks (Bloques de código)

Permiten mostrar fragmentos de código utilizando tres comillas invertidas.

```python
print("Hola mundo")

nombre = "Santiago"
print(nombre)
```

También se puede indicar el lenguaje para que GitHub aplique colores al código.

## 13. Tables (Tablas)

Permiten organizar información en filas y columnas.

```markdown
| Lenguaje | Nivel |
|---|---|
| Python | Básico |
| Java | Principiante |
| JavaScript | Básico |
```

| Lenguaje | Nivel |
|---|---|
| Python | Básico |
| Java | Principiante |
| JavaScript | Básico |

## 14. Emojis

GitHub permite utilizar emojis directamente o mediante códigos especiales.

```markdown
🚀 💻 🔥 🎯

:smile:
:rocket:
:computer:
```

🚀 💻 🔥 🎯

:smile: :rocket: :computer:

---

## Conclusión

Markdown es un lenguaje de marcado sencillo que permite crear documentos organizados y visualmente atractivos. Es especialmente útil en GitHub para elaborar archivos README, documentar proyectos y compartir información de manera clara.
